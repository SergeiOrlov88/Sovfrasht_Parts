1. Design-токены

  • Цвет: --bg #0a1420, --bg-elev #0c1826, --panel #132639, --panel2 #18324a, --panel3 #1d3c58, --line #22405c, --line2 #2c5476, --ink #eaf2fb, --ink-soft #c9d8e8, --mut #8aa6c2, --acc #2fc4a3, --acc-ink #04241c, --acc-dim, --acc-glow, --acc2 #38b6ff, --acc2-dim, --warn #f0a341, --warn-ink, --warn-dim, --danger #ff5d73, --danger-dim
  • Отступы: --s-2 8, --s-3 12, --s-4 16, --s-5 20, --s-6 24, --pad 16, --touch 48, --touch-lg 56
  • Радиусы: --radius-sm 12, --radius 16, --radius-lg 20
  • Типографика: --font Manrope, --mono IBM Plex Mono
  • Сетка: --app-max 480px — колонка приложения, не растягивать контент на десктопе

2. Переиспользуемые компоненты → React

  • AppBar — логотип + role-pill + судно/заявка
  • CaptureSlot — primary/sec, empty/filled, рамка-видоискатель, shutter, recapture
  • ConfidenceMeter — SVG-кольцо, модификаторы high / mid / low по порогам 70 / 50
  • IdentificationCard — заголовок, тип, поля, маркировка, оговорка
  • TabBar — Отчёт / Закупка / Ремонт
  • SupplierRow — логотип, цена, срок, наличие, флаг is-best
  • RepairVerdict — штамп, сравнение колонок, обязательный disclaimer
  • ModerationTaskCard — фото, предложенный результат, кандидаты, confirm/fix
  • EmptyState — пусто / ошибка / нет прав; рядом паттерны skeleton и progress-steps
